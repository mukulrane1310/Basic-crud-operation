Todo CRUD App (Basic Project)

This is a very basic CRUD project built with plain HTML, CSS, and JavaScript (no library or framework used).

What is CRUD?
Create → add a new task
Read → view all tasks in the list
Update → edit a task / mark it as completed
Delete → remove a task

Data is saved in the browser's localStorage, so no backend or database is needed — just open the file and it works.

Files
index.html — page structure
style.css — styling
script.js — CRUD logic
How to run

Just open the index.html file in your browser. No installation required.
